# Zerodha Clone 📈

A full-stack **Zerodha Clone** web application inspired by the Zerodha trading platform. This project is developed for learning and practicing full-stack web development concepts such as React, Node.js, Express, MongoDB, REST APIs, and database integration.

> **Disclaimer:** This project is created for educational purposes only. It is not affiliated with, sponsored by, or endorsed by Zerodha.

## 🚀 Features

- 📊 Dashboard for viewing holdings and positions
- 📈 Stock holdings and portfolio information
- 💰 Buy and sell order functionality
- 📝 Order management
- 📋 Holdings and positions tables
- 📊 Stock price visualization using charts
- 🔐 Backend API integration
- 🗄️ MongoDB database integration
- ⚡ REST API using Node.js and Express
- 🎨 Responsive React-based frontend

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios
- Chart.js

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API
- CORS
- dotenv
